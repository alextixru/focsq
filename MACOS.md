# Клиент CSQTT 2.5.0 для macOS

Клиент `.app` с интерфейсом существующего форка и ядром из официального
`amurcanov/csqtt` v2.5.0 (`fd936ef087c34cc46f26111dc2361f43b8b03c07`).
Сборка Universal: Apple Silicon (M1 и новее) и Intel.
Сервер в этот пакет не входит, установка сервера не выполняется.

## Запуск

1. Скачайте `csqtt-2.5.0-macos-universal.zip` из этого релиза.
2. Распакуйте и переместите `FOCSQ.app` в «Программы».
3. Запустите приложение. Это локальная ad-hoc подпись, без Apple Developer ID
   и нотарификации. Если macOS блокирует первый запуск, используйте системное
   разрешение для этого приложения в «Настройки → Конфиденциальность и безопасность».
4. Добавьте профиль своего сервера или импортируйте ссылку `csqtt://`.
5. Нажмите «Подключить». Системный запрос администратора нужен для создания
   сетевого интерфейса и установки маршрутов. При отключении помощник удаляет
   созданные маршруты и восстанавливает DNS.

## Проверки и ограничения

CI компилирует и тестирует ядро на macOS, проверяет Flutter-код, собирает `.app`,
проверяет архитектуры/подпись и запуск окна. Эти проверки не доказывают подключение
к конкретному серверу: такая проверка требует его конфигурации и доступа к сети.
Сборка использует протокол 2.5.0; совместимость с более старым сервером не заявляется.

Исходная рабочая macOS-ветка сохранена. Ядро 2.5.0 находится в `backend-v250/`;
Android, Windows, Linux и сервер этим workflow не собираются.
Авторство и лицензии исходных проектов сохранены. Это персональная сборка форка.
